# Structural Patterns

Structural patterns focus on composing classes and objects.

Packages will follow this style:

```text
src/main/java/com/training/designpatterns/structural/adapter/
src/main/java/com/training/designpatterns/structural/decorator/
src/main/java/com/training/designpatterns/structural/facade/
src/main/java/com/training/designpatterns/structural/proxy/
src/main/java/com/training/designpatterns/structural/composite/
```
