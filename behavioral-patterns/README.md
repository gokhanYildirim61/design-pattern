# Behavioral Patterns

Behavioral patterns focus on communication and responsibilities between objects.

Packages will follow this style:

```text
src/main/java/com/training/designpatterns/behavioral/strategy/
src/main/java/com/training/designpatterns/behavioral/observer/
src/main/java/com/training/designpatterns/behavioral/command/
src/main/java/com/training/designpatterns/behavioral/state/
src/main/java/com/training/designpatterns/behavioral/template/
```
